# 简历更新建议（对照当前代码实现）

> 只列**代码里真实存在、可验证**的内容。每一条后面给出证据位置，面试被追问时能立刻指出。

## 一、项目描述可以直接改成这样

**智能数据平台 | 个人全栈项目 | https://music-agent.cloud**

技术栈：Vue 3 + TypeScript + FastAPI + PostgreSQL + pgvector + DeepSeek API + Docker

- **产品定位**：面向多用户的内容数据平台，提供检索与筛选、集合管理、可解释推荐与个人画像；**不托管音频、不提供下载**（前置审批与版权约束下的合规设计）。
- **数据管道**：Jamendo 开放授权元数据 + AcousticBrainz 开源音频分析，**931 首曲目、84 位来源**；分页提交、限流退避重试、单页失败只回滚该页；每首歌落库 **21 项频谱特征 + 节奏 + 调性 + 多标签情绪**。
- **检索与推荐**：pgvector 向量检索（**1024 维**，业务数据与向量同库）；内容推荐 + 热门兜底，**显式反馈接入排序**（喜欢提升、已看过降权、不感兴趣直接排除）。
- **Agent 编排**：Function Calling 工具注册中心（9 个工具，含 2 个需用户确认的写操作：建歌单、把歌曲加进歌单）+ 白名单调用 + Pydantic 参数校验；SSE 逐字流式输出；**无进展检测**（连续重复调用掐停）+ 轮数保险丝 + 时间预算兜底，异常路径返回可读答复。
- **RAG 问答**：向量优先 + 关键词降级双路检索，相似度阈值过滤 + 相关性标记，抑制幻觉。
- **管理后台**：独立布局的管理控制台（概览统计、曲目/歌手增删改、账号角色与状态管理、导入任务），全部接口走管理员依赖。
- **工程化**：**145 个 pytest 用例**（独立测试库、覆盖鉴权/越权/事务回滚等路径）；ruff + mypy + pytest + ESLint + Prettier + vue-tsc 质量门禁；GitHub Actions **测试不过不构建不部署**，部署后自动执行 Alembic 迁移；Docker Compose + Nginx 上线。

## 三、面试前必须能回答的 6 个问题

1. **为什么不能播放？** —— 前置审批 + 版权，故意做成纯数据平台；核心是检索、特征分析、可解释推荐、RAG。
2. **energy/valence 为什么是空的？** —— AcousticBrainz 公开接口已下线，**取不到就不填**；页面如实标注，派生指标明确说明是派生的。
3. **没有收听行为，推荐靠什么？** —— 收藏 + 显式反馈；反馈权重已进排序，不感兴趣会直接排除。
4. **向量多少维？为什么？** —— 1024 维，`BAAI/bge-m3`；同库存储，批量向量化只处理空值、可重复执行。
5. **Agent 跑飞怎么办？** —— 无进展检测 + 轮数保险丝 + 时间预算，三者都走兜底收尾；异常路径也给答复。
6. **测试测了什么？** —— 145 个用例，覆盖成功/鉴权失败/资源不存在/越权/重复操作/事务回滚；迁移变更同步更新 schema 断言。
