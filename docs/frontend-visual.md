# 前端视觉与交互规范

> 目的：让界面看起来像一个真实的数据工具，而不是模板化的 AI 产品。规范只约束“表达方式”，不限制功能。

## 1. 三条原则

1. **信息优先**：能用一个数字、一行文字说清的，不加装饰性插画、光晕或大卡片。
2. **一种容器语言**：页面统一用「实色底 + 1px 边框 + 8px 圆角」。需要分组时用留白和分隔线，不再套一层卡片。
3. **交互可见但不喧哗**：hover 只改变颜色/底色，不做位移和缩放；状态变化用文案和颜色表达。

## 2. 设计令牌（`frontend/src/style.css`）

| 类别 | 取值 | 说明 |
|---|---|---|
| 背景 | `--bg #0b0c0e`、`--bg-elevated #101113`、`--surface #141519` | 只用明度分层，禁止渐变与径向光晕 |
| 文字 | `--text` / `--text-secondary` / `--text-muted` | 正文用 `--text`，辅助信息才用 muted |
| 强调色 | `--accent #d8a25e` | 全站唯一强调色，只用于交互、选中态和关键数字 |
| 语义色 | `--danger` / `--warning` / `--success` | 只表达状态，不参与装饰 |
| 圆角 | `--radius-sm 4px`、`--radius 8px`、`--radius-lg 12px` | 不再使用 16–20px 的大圆角 |
| 字号 | `--fs-xs 12` ～ `--fs-3xl 36` | 正文最小 12px，不使用 9–10px 的装饰性小字 |
| 阴影 | 只有 `--shadow` / `--shadow-soft` | 仅用于弹窗、下拉等浮层；页面容器一律不用 |

新增页面时**只允许使用令牌**，禁止在页面里硬编码主题色（AGENTS.md / CLAUDE.md 的 L1 要求）。

## 3. 排版

- 正文 14px，辅助信息 12px，标题 20–28px；页面标题不超过 28px。
- 数字（计数、BPM、百分比）统一加 `font-variant-numeric: tabular-nums`（工具类 `.numeric`）。
- 中文界面不使用全大写的英文 eyebrow，也不用 `letter-spacing: 0.16em` 这类装饰性字距。
- 说明文字不写“智能、赋能、触手可及”这类空词，写具体名词和数字。

## 4. 图标

- 统一使用 `frontend/src/components/AppIcon.vue`（内联 SVG，24×24，描边 1.6）。
- **禁止**使用 emoji（🔒 👍 🎯）和 Unicode 符号（▦ ▤ ♡ ◫ ⌕ ✦ ☰）充当图标。
- 新增图标时在 `AppIcon.vue` 的 `ICONS` 中登记 path，保持同一线宽和视觉体量。

## 5. 组件与页面模式

### 页面骨架

```
PageHeader（标题 22–28px + 一句说明 + 右侧操作）
  └ 内容区（列表 / 图表 / 表单）
  └ 状态区（加载 / 空 / 错误，统一用 StatePanel）
```

- 列表页用表头 + 分隔线，不用“每行一张卡”。
- 空态、错误态必须给出下一步动作（重试 / 清除筛选 / 去内容库）。
- 加载超过 150ms 才显示骨架（`useDelayedFlag`），避免一闪而过。

### 智能体页

- 消息按「角色标签 + 内容」两行排，不做头像、不做左右气泡。
- 用户消息给浅底块，助手回复直接排在页面底色上。
- 示例问题用编号列表，不用四张大圆角卡片。
- 工具调用状态和「需确认」面板是产品差异点，保留并保持醒目。

### 图表

- 颜色从 CSS 变量读取（`--accent`、`--text-muted`、`--chart-border`），不写死 RGB。
- 柱状图圆角不超过 2px；折线不加发光和面积渐变以外的装饰。

## 6. 交互

- 可点击元素最小高度 28px（图标按钮）/ 32px（文字按钮），间距 ≥ 8px。
- hover 只改颜色或底色，持续时间 140ms；禁止 `translateY`、`scale`、发光。
- focus-visible 统一 2px 强调色描边，偏移 2px。
- 危险操作使用 `--danger`，并且要二次确认（沿用现有确认面板）。
- 反馈必须落在页面上，不只弹 toast：成功/失败后更新对应区域的状态。
- 命令式组件（`ElMessage`、`ElMessageBox`）必须在 `main.ts` 引入对应样式，否则会出现无定位的裸块。

## 7. 窄屏约定

- ≤800px 时前台侧栏折叠成两行导航，而不是横向滚动；登录 / 控制台 / 退出放在导航最后。
- 后台侧栏折叠成顶部一行，返回入口只保留图标（带 `aria-label`）；表格在自身容器内横向滚动。
- 移动端不为省空间隐藏关键信息：列表保留「歌手 · 风格 · BPM」合并行。
- 浮层抽屉（智能体会话栏）在选中会话 / 新建对话后自动收起。
- 未知路径由 `NotFoundPage` 兜底，不出现空白壳子。
