# 演示脚本（给招聘方/面试官看）

> 目标：**3 分钟看完项目最有技术含量的部分**。每一步都对应一个可验证的技术点，不需要你解释太多。

## 0. 准备

- 打开 https://music-agent.cloud
- 登录页点 **「立即体验演示环境（只读）」**（不需要账号密码）
- 页面顶部会出现黄色「**演示账号**」横幅 —— 可以先说明：**这是只读演示，浏览全部页面但改不了数据**

## 1. 内容数据（30 秒）

进 **内容数据**，说明：

- **931 首曲目 / 84 位来源**，全部来自 **Jamendo 开放授权元数据 + AcousticBrainz 开源音频分析**
- 列表里能看到 **节拍 / 律动 / 热度**，都是真实计算出来的，不是人工填的
- 顶部搜索支持按名称、来源、标签检索（后端是分页 + 索引查询）
- 点「流派筛选」能看到动态生成的流派列表（8 类）

**要说的技术点**：数据管道是**分页提交 + 限流退避重试 + 单页失败只回滚该页**，不整批失败。

## 2. 曲目详情（40 秒）★ 重点

随便点一首，往下看：

- **时长**（从 MusicBrainz 分批补全，931/931 全覆盖）
- **音乐特征**：节拍、调性、律动、响度、人声/器乐、人声概率
- **音频特征明细**：起始速率、拍数、调性强度、和弦调性、频谱质心、频谱滚降、频谱通量、频谱熵、不协和度、动态复杂度
- **特征画像**雷达图（归一化对比）
- **情绪标签**：明亮 / 放松 / 电子 等（来自音频分析的多标签判定）

**要说的技术点**：

- 每首歌背后是 **AcousticBrainz 的 21 项频谱特征 + 节奏 + 调性**，不是简单的元数据
- 「能量」是**按响度派生的横向比较指标**，我明确标注了它不是数据源原生 energy —— **不把派生值说成原生值**
- 能量/愉悦度/乐器/曲式四个字段**数据源没有**，页面按「数据缺失」如实标注，**不用 0 或假值填充**

## 3. 个人分析（40 秒）★ 重点

进 **个人分析**，说明：

- 画像来自 **收藏 + 浏览记录 + 主动反馈**三类真实行为
- 图表：**30 天互动趋势**、**活跃时段**（能看到夜间集中）、**风格分布**、**常来源**、**偏好特征**
- 顶部有一个「**主动反馈**」计数

**要说的技术点**：

- 这个平台**不托管音频、不提供播放**（前置审批 + 版权），所以**没有收听行为**；我用**显式反馈**（喜欢/不感兴趣/已看过/类似更多）作为推荐信号
- **反馈是真的进了推荐排序**：喜欢 +0.25、看过 −0.2、不感兴趣直接排除（并且会在推荐里消失）
- 画像缓存放在 Pinia store：**二次进入秒开**，后台静默刷新

## 4. 智能助手（40 秒）★ 最高技术含量

点 **智能助手**，然后：

1. 输入「**帮我找几首适合深夜听的内容，说明推荐理由**」
   - 看 **SSE 逐字流式输出** + 顶部吸顶的**运行状态条**（正在分析 → 正在调用工具 → 正在生成）
2. 输入「**City Pop 是什么风格**」
   - 这一步会走 **RAG**：**向量优先 + 关键词降级**双路检索，阈值过滤 + 相关性标记
3. 输入「**帮我建一个集合叫夜行电台**」
   - 触发**高风险操作确认卡片**：显示要写入的内容（人话，不是 JSON），可以确认或拒绝

**要说的技术点**：

- **Function Calling 工具注册中心**：7 个工具，白名单调用 + Pydantic 参数校验
- **无进展检测**：连续重复调用同一工具即掐停；另有轮数保险丝与时间预算兜底，**异常路径也返回可读答复而不是报错**
- 事务边界在请求层统一管理，写操作走保存点，失败只回滚该步

## 5. 管理后台（30 秒）

点侧边栏 **「管理」** 按钮（只有管理员账号可见），或直接访问 `/admin`：

- **概览**：曲目/账号/歌单/收藏/反馈计数 + **流派分布** + **数据完整度**（向量 931/931、含音频特征 931/931）
- **曲目管理 / 歌手管理**：列表 + 增删改（弹窗表单）
- **账号管理**：搜索、分页、**切换角色、禁用启用**（带保护：不能降级最后一个管理员）
- **导入任务**：触发 Jamendo 导入并看进度

**要说的技术点**：后台是独立布局，接口全部走管理员依赖；**演示账号虽然能看后台，但写操作被后端按 `DEMO_USERNAME` 拦成 403**。

## 6. 工程与交付（口头说明，30 秒）

- **测试**：**145 个 pytest 用例**，在独立测试库上跑，覆盖成功/鉴权失败/资源不存在/越权/重复操作/事务回滚
- **质量门禁**：ruff + mypy + pytest + ESLint + Prettier + vue-tsc，**CI 里测试不过就不构建镜像、不部署**
- **部署**：Docker Compose（后端 + 前端 + pgvector）+ Nginx + GitHub Actions，**部署后自动执行数据库迁移**
- **迁移**：13 个 Alembic 版本，每次结构变更都同步更新 schema 断言测试

## 面试可能追问 & 准备答案

| 问题 | 答案要点 |
|---|---|
| 为什么不能播放音乐？ | 前置审批 + 版权，**故意做成纯数据平台**：检索、特征分析、可解释推荐、RAG 问答才是核心 |
| energy/valence 为什么空着？ | AcousticBrainz 公开接口已下线，**取不到就不填**，页面如实标注，不造数据 |
| 没有收听数据怎么做推荐？ | 用**显式反馈 + 收藏**作为信号；反馈权重已接入排序（喜欢提升、不感兴趣排除） |
| 模型的流派判定准吗？ | 是**音频分类模型的判定，不是官方流派**；库里同时存了 4 套体系的标注，页面用多体系投票并注明"模型判定" |
| 智能体跑飞了怎么办？ | 无进展检测（连续重复调用掐停）+ 轮数保险丝 + 时间预算，三者都走**兜底收尾**，保证有答复 |
| 向量多少维？为什么？ | **1024 维**，模型是 `BAAI/bge-m3`；业务数据与向量同库（pgvector），批量向量化只处理空值，可重复执行 |
